# remotectl

Home agent for [remote-control](https://github.com/IvanBBaev/remote-control): approve,
answer and start AI coding agent sessions (Claude Code first) from your phone, end-to-end
encrypted through a metadata-only relay.

```sh
npm install -g remotectl
remotectl --help
```

Requires Node 22 or later. The package is a single bundled file with no dependencies and
no install scripts; every release is published from GitHub Actions with npm provenance.
